# Upstream

TeachX is an independent, simplified reimplementation inspired by:

- Project: DeepTutor
- Repository: https://github.com/HKUDS/DeepTutor
- Upstream snapshot used: `DeepTutor-main` downloaded on 2026-10-01
- Upstream license: Apache License 2.0

The original frontend under `frontend/` is reused under the Apache-2.0
license. A copy of the upstream license is kept at
`third_party/DeepTutor-LICENSE`.

The TeachX backend and runtime are being rewritten with a smaller, focused
feature set. This repository is not an official DeepTutor repository.
