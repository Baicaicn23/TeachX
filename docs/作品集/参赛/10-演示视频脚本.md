## 三、RAG 问答：每个回答都有出处（约 1 分 10 秒）⭐核心

**目的**：这是产品最硬的能力——**回答基于你的资料，并且告诉你出处**。

| | |
| --- | --- |
| **操作** | 回主页 → 输入框附近点「资源/知识」→ 勾选 **高等数学-微积分** |
| **输入** | `结合我的知识库，用通俗的例子讲讲定积分和不定积分有什么区别？` |
| **预期** | ① 回答**逐字流式出现**；② 回答里带 `[序号]` 引用标记；③ 回答下方出现**来源引用**（哪个文件、哪一段）；④ 底部显示**本轮 token 消耗** |
| **讲解词** | "注意三件事。第一，回答是**流式**出来的，不用等整段生成完。第二，回答里这些方括号是**引用标记**，下面列出了它到底看了我哪份资料、哪一段——**它真的翻了资料，不是编的**。第三，底部是本轮消耗的 token 数，真实模型按量计费，这里对用户透明。" |

> **若出错**：如果回答里没有引用标记，说明这次没触发检索。
> **加一句"结合我的知识库"通常就能触发**；实在不行换个问法重录这一条。

## 四、意图路由：同一句话，不同处理（约 1 分 20 秒）⭐核心

**目的**：展示"不是一条链路打天下"——AI 先判断你想干嘛，再交给不同的子 agent。

**操作**：**连着问下面四个问题**，每问完停两秒让状态条显示出来。

| # | 输入（复制粘贴即可） | 预期：意图 / 子 agent | 预期：工具/行为 |
| --- | --- | --- | --- |
| 1 | `什么是矩阵的特征值和特征向量？` | 概念讲解 → tutor | 可能检索，给出讲解 |
| 2 | `帮我算一下 ∫(3x²+2x)dx 从 0 到 2 的值` | 计算 → calculator | **调用计算器工具**，状态条显示工具调用次数 |
| 3 | `四级作文有哪些万能句型？`（切到**大学英语四级**库） | 资料检索 → retriever | **调用知识检索**，给出引用 |
| 4 | `根据我的知识库给我出 2 道练习题，先不给答案`（选中**高等数学-微积分**库） | 做题练习 → practice | **调用知识检索**（能读资料才出得了"基于你资料"的题），但**不写数据** |

**讲解词**：

> "同一个输入框，四种问法，走的是**四条不同的处理链路**。
> 我先做了一个意图识别——判断你是在问概念、要算数、找资料，还是要练习——
> 然后路由到对应的**子 agent**，每个子 agent 有自己的提示词和**自己的工具权限**。
>
> 注意第四个：练习 agent **能读不能写**——它拿得到检索工具（不然"基于我的
> 资料出题"就是空话），但**写工具在它这里是黑名单**。出题不该改动我的数据，
> 这句话是在执行层强制的，不是靠提示词劝模型。"

> **若出错**：第 3 条如果判成了闲聊（不给引用），把问法改成
> `结合我的四级资料，作文有哪些万能句型？` 重录。

| | |

### 8.3 拿错题出新题 ⭐（本段是功能重点，约 40 秒）

**目的**：展示"错题不是备忘录，是会自己长出练习题的材料"。

| | |
| --- | --- |
| **操作** | 在学习记录里点刚才那条误区旁的 **「用它出练习题」**；或回练习页把**来源**切成「来自我的错题」→ 生成 |
| **预期** | 生成一道**新的**题，考的是同一个知识点；题卡上带一个 **「来自你的误区」** 标签 |

## 十二、别做的事（避开已知弱点）

演示时**不要**碰下面这些，它们有已知缺陷，录进去会难看：

| 别做 | 原因 |
| --- | --- |
| 用**很短的两三个字**问知识性问题（如"讲讲熵"） | 有些问法模型判断不足会**不去检索**，直接用通识回答。请统一加"**结合我的知识库**"这类措辞 |
| 问知识库里**没有**学科的问题（比如没建的库） | 它不会主动说"库里没有"，而是直接用自己的知识答。避免现场翻车 |
| 连着快速发问、不等上一条回答完 | 别抢时间，等状态条出现"已完成"再发下一条 |
| 把模型连接页的 Key 明文拍进画面 | 演示"模型连接"页时注意**别露出密钥**（页面上本身不回显，但别手输） |

> **2026-10-08 移除一条**：原来这里写着"别在聊天框里问出题"——那是因为练习
> 子 agent 当时被禁掉了检索，会答"我看不到你的知识库"。现在它改成**只读**了，
> §四 第 4 条演示的就是这个，可以放心问。
