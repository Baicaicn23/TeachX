## 二、第三方品牌图标 ⚠️ 本节需要提交前处理

这三组图标是**上游遗留资源**，被本地 vendor 到 `frontend/public/` 以便离线使用。
来源均有记录，但**其中的品牌 logo 属于第三方商标**，且对应的功能在本作品中
**未实现或已从导航移除**。

### 2.1 `public/provider-icons/` — 模型供应商图标

| 项 | 说明 |
| --- | --- |
| 来源 | `@lobehub/icons-static-svg`（代码注释见 `components/common/ProviderIcon.tsx:6`） |
| 许可证 | **MIT** |
| 用途 | "模型连接"页展示供应商标识（DeepSeek / OpenAI 等） |
| 商标归属 | 各供应商商标归各自所有 |
| 判定 | ✅ 许可证清晰；用于**识别真实接入的供应商**，属正常指代性使用 |

### 2.2 `public/knowledge-engine-icons/` — 知识引擎图标 ⚠️

| 文件 | 来源 | 归属 |
| --- | --- | --- |
| `llamaindex.png` | run-llama GitHub 组织头像 | LlamaIndex |
| `pageindex.png` | VectifyAI GitHub 组织头像 | VectifyAI |
| `graphrag.png` | Microsoft GitHub 组织头像 | Microsoft |
| `lightrag.jpg` | HKUDS GitHub 组织头像 | HKUDS / LightRAG |
| `tencent-ima.svg` | `static.ima.qq.com` | 腾讯 ima |
| `obsidian.svg` | `obsidian.md` | Obsidian |
| `marginnote.png` | `marginnote.com` | MarginNote |

来源已由上游记录在 `public/knowledge-engine-icons/README.md`，并声明
"The product/vendor marks remain the property of their respective owners."

⚠️ **风险**：这些图标仍被 `KnowledgeEngineIcon.tsx` 引用，并在
`KnowledgeHome.tsx` / `KnowledgeBaseDetail.tsx` / `CreateKbModal.tsx` /
`EngineDetail.tsx` 中渲染。**但这些"知识引擎"（LlamaIndex / GraphRAG / LightRAG /
Obsidian / MarginNote / 腾讯 ima）本作品一个都没有实现**——它们对应的界面属于
上游遗留的**死 UI**（有入口、无后端）。

**建议处理**：在参赛版本中**移除这批图标及其渲染入口**。理由有两条：

1. **授权风险**：使用第三方品牌 logo 去标识一个**并不存在的功能**，缺乏正当理由，
   容易被质疑为暗示关联；
2. **作品质量**：评分标准要求"需求与业务逻辑""核心功能"清晰。展示未实现的功能
   入口会让评委认为作品不完整——这正是本项目开发规则里"**每个按钮背后必须有
   真实后端，没有就删**"的原因。

> 该项目已把"UX 清理批①③"列入开发工作队列（清理资源弹窗与知识库详情页的死分类），
> 授权清理应与之一并完成。
