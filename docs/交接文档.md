## 项目目标

TeachX 是一个 Web 优先的 AI 学习平台：浏览器聊天与流式回答、Agent Loop 和工具调用、
用户知识库与 RAG、学习档案与个性化、练习复习闭环、用户自带模型连接。
完整介绍见根目录 [README](../README.md)。

当前明确暂缓：管理员用户管理、Docker 实机构建、PostgreSQL 迁移、复杂插件市场。

## E1、E2 已完成：不要重做

### E1：工具执行政策与重试（进入 `502bbcd`）

- 工具用 `ToolPolicy` 声明只读、最大尝试、超时和退避；`None` 继承默认值。
- 错误分类：`ToolError` 永久不重试；`ToolTransientError` 临时可重试；
  `ToolTimeoutError` 超时可重试。SQLite locked 自动转为临时错误。
- `tool_result` 事件携带 `attempt_count`、`retry_count`、`retry_delays_ms`、
  `duration_ms`、`error_code`、`retryable`、`timed_out`。
- 测试：`backend/tests/test_tool_reliability.py`；教程 19 有 15 个面试问答。

### E2：工具执行幂等保护（进入 `cfaab58`）

- 幂等键 = SHA-256(user_id|session_id|turn_id|call_id|tool_name|参数指纹)，
  参数只存 hash 不存原文，跨用户不共享记录。
- `tool_executions` 表唯一约束 + 原子插入实现并发控制；completed 重放、
  永久失败重放、可重试失败接管、stale running 可接管。
- `tool_result` 事件新增 `deduplicated`、`replayed`、`execution_status`、
  `idempotency_key_hash`。
- 测试：`backend/tests/test_tool_idempotency.py`（10 个）。
- 设计细节和真实验证记录见教程 19 第 11～12 章和第 16～23 题面试问答。

## 已知限制与坑

- 新用户首次注册自动登录，第一用户是管理员。
- 旧用户 `onboarding_completed` 迁移默认已完成；新用户明确写为未完成。
- 学习目标修改文字时自动 active，完成状态不会被旧值覆盖。
- 已完成学习目标不进入提示词，但其他档案字段继续存在。
- 知识库名称目前全局唯一，不同用户不能创建同名知识库。
- 原 DeepTutor 前端仍有大量非当前主线的页面，只保证交接文档中列出的路径完成验证。
- 旧的 `/learning/practice` 页面保留兼容；新的普通用户练习入口是 `/practice`。
- 模型连接只用于聊天 Provider，不用于 Embedding。
- `TEACHX_AUTH_SECRET` 变化会使已有用户模型 Key 无法解密。
- 日预算默认关闭；真实模型测试仍应少打、短问，优先使用 Mock。
- usage 依赖供应商返回值；缺失时 TeachX 会估算并标记 `estimated`。
- 工具有有限重试和幂等执行记录；“执行成功后写终态失败”的窗口在 stale 接管时
  仍可能重复执行副作用，教程 19 有说明。
- 还没有固定评测数据集、离线回放、Recall@K/MRR、trace 和回归 dashboard。
- 还没有 MCP Client/Server、完整权限审批和沙箱执行。
- 还没有模型复杂度路由和可恢复的 durable workflow。
- Docker、PostgreSQL 和管理员用户管理不是当前阻塞项。

## 开发规则

每个大型功能必须完成：

```text
明确用户场景
→ 代码
→ 自动测试
→ 浏览器或 API 验证
→ 中文教程
→ 更新 README（影响用户时）
→ 更新 开发路线图
→ commit
→ push
```

每次任务结束前都要做文档判定。新功能必须补中文教程，小修复至少检查现有文档
是否失真。写作规则见 [规范/文档写作指南.md](规范/文档写作指南.md)。

不要：

- 在没有验证的情况下声称真实模型或线上环境完成。
- 在自动测试中读取本地真实 API Key。
- 输出或提交任何 Secret。
- 重写已经稳定的 Agent Loop。
- 删除用户本地数据库或知识库原文。
- 继续投入 Docker 或管理员功能，除非用户明确恢复。
