# TeachX 使用指南：前十分钟上手

> 写给第一次打开 TeachX 的人。TeachX 只做一件事：**一个懂你的学习助手**——
> 回答有出处、会算题、能出题复习、记得你说过的话。其他一切界面都为这一件
> 事服务。本指南带你走完前十分钟，之后你自然会玩。

## 你会看到的界面（只有五个入口）

| 位置 | 页面 | 干什么 |
| --- | --- | --- |
| 左侧栏 · 主页 | `/chat` | **90% 的时间在这里**：聊天框 + 知识库选择 |
| 左侧栏 · 练习 | `/practice` | 从你的知识库生成练习题、复习排期、掌握度 |
| 左侧栏 · 学习记录 | `/learning-records` | 你给回答的反馈、记录的错题误区 |
| 左侧栏 · 模型连接 | `/model-connections` | 填自己的 DeepSeek/OpenAI Key |
| 左侧栏 · 设置 | `/settings` | 头像、学习档案、目标、个性化开关 |

个人主页在右上角头像 → 个人资料（年龄/年级/讲解风格/目标进度）。

## 前十分钟怎么走

### 第 1 分钟：注册登录

首次打开会要求注册。**第一个注册的账号自动是管理员**，能看到全部知识库。

### 第 2~4 分钟：让助手认识你

登录后先进 **设置 → 个人资料**：填年级（如"大学一年级"）、讲解风格
（推荐"先例子后原理"）、学习目标（如"掌握微积分基础"）。这些会注入每
一次回答——关闭个性化开关则全部失效。

### 第 5~7 分钟：选知识库，开始问

回主页，点击输入框附近的 **"资源"**，勾选一个知识库（比如"微积分基础"），
然后直接说话。不知道说什么就用输入框下方的三个建议按钮，比如
"结合我的知识库，用通俗的例子讲讲什么是极限"：

- 回答下方会出现 **来源引用**（哪个文件哪一段）——它真的翻了你的资料；
- 回答底部显示本轮 **token 消耗**——真实模型按量计费，这里透明可见。

**知识库里没有的东西它会直说**——这时你可以上传自己的笔记
（主页 → 资源 → 上传），或换一种问法。

### 第 8~10 分钟：让它算题、出题、记住你

直接说这三种话，感受三种不同的工作方式：

```text
帮我算一下 37 * 43，并解释步骤        ← 自动调用计算器,不心算
围绕我的知识库出 3 道练习题,先不给答案  ← 出题模式,答案你说完再对
记住：我在准备月底的微积分测验         ← 写进长期记忆
```

之后**新开一个对话**问"帮我规划一下复习"——它会记得你的测验（长期记忆），
并围绕你设置的目标展开（学习目标在设置里改，进度条在聊天页顶部实时显示）。

## 日常怎么用（一分钟循环）

```text
有资料 → 上传到知识库
有题目 → 聊天里说"把这道题存进 XX 库：题目原文"——随手沉淀,期末有得复习
有疑问 → 主页提问(选对知识库,回答带出处)
听懂了 → 去 /practice 做题巩固,四级自评定复习日
没懂   → 点"记录我的误区",之后可在 /learning-records 回看、带回聊天重问
```

**沉淀是这套工具的灵魂**：作业系统的题目散着不整理，期末就没得复习。
平时做作业时顺手说一句"把这道题存进微积分基础：……"，题目就带日期进了
你的学科库；到期末，从库里生成练习题重刷，或者让助手基于库里攒的题目
帮你划重点。

**存进去的东西在哪看**：主页输入框旁的"知识"选择器，展开每个知识库——
最近沉淀的文件（名称 + 日期）直接列在库名下面，最新三个一目了然。

## 进阶

- **换模型**：模型连接页填自己的 Key（服务端加密存储，接口不回显），
  或一键切回平台默认。
- **停止记忆**：设置里关闭个性化（记忆仍在库里，可到 `/api/auth/memories`
  逐条删除）。
- **看它的工作过程**：浏览器 DevTools → Network → WS，每个回合的事件流
  （意图、工具调用、引用）都在里面。

## 常见问题

| 现象 | 说明 |
| --- | --- |
| 回答说"知识库里没有找到" | 选错知识库,或资料确实没有——换个说法或上传资料 |
| 改了档案/目标,回答没变化 | 从下一回合生效;流式进行中的回答不变 |
| 回答一半停了,提示可重试 | 触发了超时或预算保护,点重试即可;已生成的部分保留 |
| 侧边栏有些页面打开很简陋 | TeachX 聚焦学习助手,未实现的上游页面已从导航移除 |
| 忘记密码 | 目前无找回流程,联系管理员重置(学习版边界) |
