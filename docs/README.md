## 目录结构

```text
docs/
├── README.md        文档总导航(本文件)
├── 交接文档.md       Agent/开发者接手入口:当前状态、下一步、敏感文件边界
├── tutorials/       教程:20 篇,按学习顺序编号,含面试问答
├── 参考/            查事实:架构、API、数据库表、配置(不教为什么)
├── 规划/            计划与依据:开发路线图、技术栈调研
└── 规范/            写文档的规则:文档写作指南(含 README 维护规范)
```

## 目录分类标准

本项目的文档分类遵循 [Diátaxis](https://diataxis.fr/) 框架——业界通用的文档
组织方法,核心思想是"不同目的的文档分开放,不要混成一锅":

| 目录 | 对应类型 | 判定标准 |
| --- | --- | --- |
| `tutorials/` | 教程 Tutorial | 学习导向:带你从零走一遍,解释为什么 |
| `参考/` | 参考 Reference | 信息导向:查准确事实,不讲背景 |
| `规划/` | 解释 Explanation | 理解导向:为什么这样做、接下来做什么 |
| `规范/` | 写作规则 | 元文档:怎么写好前面的文档 |

新文档放哪?问一句:读者是来**学**的(→ tutorials)、来**查**的(→ 参考)、
来**理解决策**的(→ 规划),还是要**写文档**的(→ 规范)。
