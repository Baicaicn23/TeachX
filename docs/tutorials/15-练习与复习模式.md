# 15：练习与复习模式

## 这一章解决什么问题

聊天和错题记录能帮助用户理解一次问题，但学习还需要主动回忆：

```text
读过内容
→ 合上资料，用自己的话解释
→ 判断解释质量
→ 未来再次复习
→ 观察掌握度变化
```

U5 把用户知识库中的文本片段转成开放式回忆题，并保存作答、复习时间和掌握度。

它不是旧 question-notebook 系统的替代，也不依赖尚未实现的兼容接口。U5 是直接接入
TeachX 当前用户、知识库和 SQLite 数据边界的一条新垂直切片。

## 为什么从知识库片段生成

练习题来源于用户已经上传的资料：

```text
knowledge_chunks
→ 选择一个还没有生成过题目的片段
→ 创建一个开放式问题
→ 保存 source_chunk_id
```

问题模板要求学习者：

- 用自己的话解释。
- 说明核心概念。
- 说明关键关系。
- 给出一个具体例子。

同一个用户和同一个文本片段只能生成一道题，唯一约束是：

```text
UNIQUE(user_id, source_chunk_id)
```

这样刷新或重复点击不会无限生成重复题。

## 数据表

U5 新增三张表。

### 1. practice_questions

保存题目、来源知识库、来源文本片段和资料摘录。

### 2. practice_attempts

保存每次作答：

```text
answer
rating
interval_days
due_at
mastery_score
created_at
```

历史作答不会被覆盖，因此以后可以分析学习者是否逐渐掌握。

### 3. practice_progress

每个用户、每个知识库保存一条汇总：

```text
mastery_score
attempt_count
updated_at
```

主键：

```text
(user_id, knowledge_base)
```

## 复习间隔怎样计算

当前使用简单、可解释的四级自评：

| 选择 | 含义 | 掌握度变化 | 下次复习 |
| --- | --- | ---: | ---: |
| Again | 还不能解释 | -10 | 1 天后 |
| Hard | 只记得一部分 | 0 | 2 天后 |
| Good | 能解释主要内容 | +8 | 4 天后 |
| Easy | 能解释并应用 | +12 | 7 天后 |

掌握度最小为 0，最大为 100。

这不是完整的 SM-2 或 FSRS 算法。它先建立可预测、可测试的复习闭环，以后可以替换
调度策略而不改变前端接口。

## 获取练习队列

队列包含：

- 从未做过的新题。
- 已经到期或过期的题。

如果刚做完一道“Good”，它会安排到 4 天后，因此立刻刷新时不会再次出现。

即使当前没有到期题，摘要仍会返回最近一次未来复习时间，页面可以显示“下次复习”。

## 后端接口

```text
GET    /api/practice/summary
GET    /api/practice/knowledge-bases
GET    /api/practice/queue
POST   /api/practice/generate
POST   /api/practice/questions/{question_id}/answer
DELETE /api/practice/questions/{question_id}
```

生成练习题：

```json
{
  "knowledge_base": "练习资料",
  "count": 3
}
```

提交作答：

```json
{
  "answer": "内存负责运行时快速访问，硬盘负责长期持久化。",
  "rating": "good"
}
```

所有接口都通过当前登录用户查询题目和知识库。用户二不能看到、回答或删除用户一的题。

核心代码：

- `backend/src/teachx/practice/service.py`
- `backend/src/teachx/api/routes/practice.py`

## 前端页面

页面地址：

```text
/practice
```

页面包含：

- 当前到期题数量。
- 练习题总数。
- 平均掌握度。
- 每个知识库的掌握度。
- 当前练习题和回答输入框。
- Again、Hard、Good、Easy 四个自评按钮。
- 生成更多练习的知识库选择器。
- 无资料时的知识库入口。

前端 API：

```text
frontend/lib/practice-review-api.ts
```

## 一次真实流程

```text
上传 memory.txt 到“练习资料”
→ 打开 /practice
→ 选择“练习资料”
→ 生成 1 道题
→ 用自己的话回答内存与硬盘的区别
→ 选择 Good
→ 掌握度更新为 8%
→ 下次复习安排到 4 天后
→ 刷新后不再出现到期题
→ 页面显示下一次复习日期
```

## 自动测试

后端：

```text
backend/tests/test_practice.py
```

覆盖：

- 从知识库片段生成练习题。
- 新题进入练习队列。
- 用户二看不到用户一的题目。
- 用户二不能回答或删除用户一的题。
- Good 更新掌握度并安排 4 天后复习。
- 摘要返回题目数、作答次数、掌握度和下次复习时间。
- API 正常路径和非法 rating 422 路径。

前端：

```text
frontend/tests/practice-review-api.test.ts
```

覆盖摘要、生成、队列和作答请求。

## 当前边界

- 当前没有自动判定开放题答案，正确性由学习者自评。
- 复习间隔是固定映射，不根据历史难度动态调整。
- “掌握度”是练习自评形成的启发式分数，不是考试成绩。
- 旧 `/learning/practice` 页面仍保留用于兼容，新的普通用户入口是 `/practice`。
- U5 尚未把练习结果注入答题模型提示词，跨会话掌握度提示可在后续迭代接入。
