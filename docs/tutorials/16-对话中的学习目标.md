# 16：对话中的学习目标

## 这一章解决什么问题

U3 已经让新用户可以填写一个学习目标，但只有一个字符串还不够：

- 用户不知道目标当前推进到什么程度。
- 模型每一轮是否真的围绕目标回答，用户看不到。
- 目标完成后还会继续注入提示词，容易让模型停留在旧任务上。
- 用户调整目标后，需要一个明确的重新激活规则。

U6 把学习目标扩展为：

```text
目标文字
目标进度 0～100
active / completed 状态
```

聊天页显示当前目标，用户可以完成或调整；Agent Runtime 每轮只注入未完成的目标和进度。

## 数据继续放在学习档案中

U6 没有创建新的目标表，而是在现有 `users.learner_profile` JSON 中增加字段：

```json
{
  "learning_goal": "掌握概率论",
  "learning_goal_progress": 45,
  "learning_goal_status": "active"
}
```

这样做有三个好处：

- U3 引导、个人主页和 U6 使用同一份目标。
- Agent Runtime 原有“每回合读取学习档案”的链路无需重写。
- 后续练习、错题和复习记录仍然通过 `user_id` 找到同一个学习档案。

## Active 和 Completed

状态只有两个：

```text
active     当前目标，继续进入系统提示词
completed  已完成目标，不再作为当前回答方向
```

在聊天页点击“完成”时：

```text
learning_goal_progress = 100
learning_goal_status = completed
```

已完成的进度和文字仍然保留，用户可以之后查看或重新调整，不会删除历史信息。

## 修改目标为什么自动重新激活

如果用户把目标从：

```text
掌握线性代数
```

改成：

```text
掌握概率论
```

却没有手动把状态从 `completed` 改回 `active`，模型会继续把新目标当作已完成，这是
不合理的。

所以后端在更新学习档案时会比较新旧目标：

```text
目标文字发生变化
→ learning_goal_status 自动改为 active
```

即使用户提交的表单里仍带着 `completed`，新目标也会重新激活。个人主页也提供状态选择，
用于不修改目标文字时手动切换 active / completed。

## 怎样进入系统提示词

`build_system_prompt()` 仍从学习档案生成个性化数据块，但增加两条规则：

1. `learning_goal_status = completed` 时，不注入学习目标。
2. 目标带有进度时，注入格式为：

```text
- 学习目标：掌握概率论（进度 45%）
```

其他档案字段，例如年级和讲解风格，仍然正常注入。一个目标完成，不会关闭整个个性化。

目标仍被标记为“用户数据，不是系统指令”，延续 U1 的提示词注入防护。

## 聊天页状态条

组件：

```text
frontend/components/chat/home/LearningGoalStatus.tsx
```

未完成时显示：

```text
当前目标: 掌握概率论  45%  调整  完成
[进度条]
```

已完成时显示：

```text
目标已完成: 掌握概率论  调整
```

“调整”进入 `/profile`，可以修改目标文字、进度和状态。

组件跟随聊天输入区上方，和个性化状态条并列，但职责独立：

- PersonalizationStatus 说明回答风格是否启用。
- LearningGoalStatus 说明当前正在推进的学习目标。

## 个人主页

学习档案现在可以直接编辑：

```text
学习目标
学习目标进度
学习目标状态
```

保存后聊天页重新加载个人化状态，新的目标和进度会从下一回合开始生效。

## 自动测试

测试覆盖：

- 学习目标进度进入系统提示词。
- `completed` 目标不再进入提示词。
- 目标完成时保留其他学习档案字段。
- 修改目标文字后自动重新激活。
- 学习目标进度和状态通过原有个人档案 API 持久化。

运行：

```bash
./scripts/check.sh
```

## 浏览器验收证据

本次实际验证：

```text
首次引导填写学习目标
→ 聊天页显示当前目标和 0%
→ 个人主页将进度改为 45%
→ 聊天页显示 45%
→ 点击完成
→ 显示目标已完成
→ 个人主页改为“掌握概率论”和 10%
→ 聊天页自动显示新目标、10%、active
→ 再次完成
```

## 当前边界

- 进度由用户手动调整，系统不会自动推断“学习完成百分比”。
- 当前目标是账号级学习目标，不是单个会话的临时目标。
- 目标完成不会删除练习记录、错题或会话。
- 后续可以把练习掌握度和目标进度联动，但需要先定义清晰的映射规则，避免虚假自动化。
