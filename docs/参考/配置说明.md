# 配置说明

> 本文是 TeachX 全部环境变量的速查表。权威来源是
> `backend/src/teachx/config.py`(变量定义)和 `scripts/check.sh`(测试强制覆盖)。
> 配置通过 `TEACHX_` 前缀的环境变量或 `backend/.env` 文件设置。
> 本文更新于 2026-10-02。

## 模型与 Provider

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `TEACHX_LLM_PROVIDER` | `mock` | 模型提供方:`mock` 或 `openai`(所有 OpenAI 兼容平台都用 `openai`) |
| `TEACHX_MODEL` | `gpt-4.1-mini` | 默认模型名,如 `deepseek-flash` |
| `OPENAI_API_KEY` | 无 | 模型 API Key(注意:此变量没有 `TEACHX_` 前缀) |
| `OPENAI_BASE_URL` | 无 | OpenAI 兼容平台地址,如 `https://api.deepseek.com/v1` |
| `TEACHX_TEMPERATURE` | `0.2` | 采样温度 |
| `TEACHX_MAX_AGENT_ROUNDS` | `6` | 一次回合内最多几轮工具调用循环 |
| `TEACHX_INCLUDE_STREAM_USAGE` | `true` | 流式接口是否请求 token 用量 |

## 上下文与费用预算

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `TEACHX_MAX_OUTPUT_TOKENS` | `1024` | 单次生成的输出 token 上限 |
| `TEACHX_MAX_HISTORY_MESSAGES` | `24` | 进入提示词的历史消息条数上限 |
| `TEACHX_MAX_HISTORY_CHARS` | `16000` | 历史消息总字符上限 |
| `TEACHX_MAX_TOOL_RESULT_CHARS` | `6000` | 单个工具结果传给模型的字符上限 |
| `TEACHX_DAILY_TOKEN_BUDGET` | `0` | 每日 token 预算,`0` 表示关闭 |
| `TEACHX_BUDGET_EXCEEDED_ACTION` | `block` | 超预算行为:`block` 阻止调用 / `mock` 回退 Mock |
| `TEACHX_GENERATE_TITLES` | `false` | 是否用模型生成会话标题(会额外消耗 token) |

## 工具执行

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `TEACHX_TOOL_MAX_ATTEMPTS` | `3` | 工具最大尝试次数 |
| `TEACHX_TOOL_TIMEOUT_SECONDS` | `30` | 单次工具执行超时(秒) |
| `TEACHX_TOOL_RETRY_BASE_DELAY_MS` | `200` | 重试退避基础延迟(毫秒) |
| `TEACHX_TOOL_RETRY_MAX_DELAY_MS` | `2000` | 重试退避最大延迟(毫秒) |
| `TEACHX_TOOL_IDEMPOTENCY_ENABLED` | `true` | 工具幂等保护开关,关闭后退回无去重行为 |
| `TEACHX_TOOL_EXECUTION_STALE_SECONDS` | `300` | `running` 执行记录多少秒后视为可接管(崩溃恢复) |
| `TEACHX_TOOL_REDACTION_ENABLED` | `true` | 敏感参数脱敏开关,关闭后事件和记录中参数原样保留 |

## 嵌入与知识库

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `TEACHX_EMBEDDING_PROVIDER` | `mock` | 向量嵌入提供方,`mock` 或 `openai` |
| `TEACHX_EMBEDDING_MODEL` | `text-embedding-3-small` | 嵌入模型名 |
| `TEACHX_DATABASE_PATH` | `data/teachx.db` | SQLite 数据库路径 |
| `TEACHX_KNOWLEDGE_ROOT` | `data/knowledge` | 知识库原文存储目录 |
| `TEACHX_MAX_UPLOAD_BYTES` | `20971520` | 上传文件大小上限(默认 20 MB) |

## 认证

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `TEACHX_AUTH_ENABLED` | `false` | 是否启用登录认证 |
| `TEACHX_AUTH_SECRET` | 开发默认值 | JWT 和用户 Key 加密密钥,**必须替换**;改动后已保存的用户模型 Key 将无法解密 |
| `TEACHX_AUTH_COOKIE_NAME` | `dt_token` | 登录 Cookie 名 |
| `TEACHX_AUTH_COOKIE_SECURE` | `false` | HTTPS 部署时必须改为 `true` |
| `TEACHX_AUTH_TOKEN_TTL_MINUTES` | `1440` | 登录态有效期(分钟) |

前端配套:`frontend/.env.local` 中设置 `NEXT_PUBLIC_AUTH_ENABLED=true`。

## 自动测试的强制覆盖

`./scripts/check.sh` 会强制以下覆盖,**不要移除**:

```text
TEACHX_LLM_PROVIDER=mock       # 自动测试绝不消耗真实 API 额度
TEACHX_EMBEDDING_PROVIDER=mock
TEACHX_AUTH_ENABLED=false      # 测试在无 Cookie 的确定性环境运行
```

这样即使本地 `.env` 配置了真实付费模型,跑测试也是安全的。

## 只开发界面时的最小配置

```bash
TEACHX_LLM_PROVIDER=mock \
TEACHX_EMBEDDING_PROVIDER=mock \
TEACHX_DATABASE_PATH=/tmp/teachx-mock.db \
TEACHX_KNOWLEDGE_ROOT=/tmp/teachx-mock-knowledge \
./scripts/dev.sh
```

本地真实的 `backend/.env`(含 API Key 和认证 Secret)被 Git 忽略,不要提交、
不要把值打印到任何文档或聊天中。
