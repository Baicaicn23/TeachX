# 数据库表结构

> 本文是 TeachX SQLite 数据库的表速查表。权威来源是建表脚本
> `backend/src/teachx/storage/database.py`——所有新表和索引都以它为准。
> 本文更新于 2026-10-02。

## 当前主要表

| 表 | 存什么 |
| --- | --- |
| `users` | 用户账号、角色、头像、学习档案、引导状态 |
| `sessions` | 聊天会话(标题、偏好、状态) |
| `messages` | 会话消息(内容、事件流、附件、父子关系) |
| `knowledge_bases` | 知识库(名称、描述、所有者) |
| `knowledge_documents` | 知识库文档(文件元数据和提取文本) |
| `knowledge_chunks` | 文档切块(用于检索的文本片段) |
| `knowledge_chunks_fts` | FTS5 全文索引(虚拟表) |
| `knowledge_chunk_vectors` | 文本块的向量索引 |
| `answer_feedback` | 回答反馈与误区记录 |
| `user_memories` | 跨会话长期记忆(规则抽取的"关于用户的事实",可列举/删除) |
| `practice_questions` | 练习题 |
| `practice_attempts` | 练习作答记录 |
| `practice_progress` | 按知识库的掌握度 |
| `model_connections` | 用户模型连接(API Key 加密存储) |
| `tool_executions` | 工具执行记录(幂等去重,见下) |
| `llm_usage` | 模型调用 token 用量 |

## 用户数据隔离(所有权字段)

每个用户的数据表都带所有者字段,查询时必须按它过滤:

```text
sessions.user_id
knowledge_bases.owner_id
answer_feedback.user_id
user_memories.user_id
practice_questions.user_id
practice_attempts.user_id
practice_progress.user_id
model_connections.user_id
```

规则:

- 普通用户只能读写自己的数据。
- 管理员跨用户能力只应用于已存在的资源查询路径(如查看全部知识库)。
- 新增接口不要默认给普通用户开放全量数据。

## 用户档案关键字段

```text
users.avatar                        头像文件名
users.learner_profile               学习档案 JSON(年级、目标、讲解风格等)
users.personalization_enabled       是否启用个性化
users.onboarding_completed          是否完成首次引导
users.learner_profile.learning_goal             当前学习目标
users.learner_profile.learning_goal_progress    目标进度(0-100)
users.learner_profile.learning_goal_status      目标状态(active / completed)
```

## tool_executions(工具执行记录)

用于工具调用幂等保护:同一业务请求只执行一次,重复请求重放已保存结果。

```text
idempotency_key TEXT PRIMARY KEY    幂等键(唯一约束即并发控制)
user_id / session_id / turn_id / call_id / tool_name
arguments_hash TEXT                 参数 SHA-256 指纹(不存原始参数)
read_only INTEGER                   工具是否只读
status TEXT                         running / completed / failed
result_content / result_metadata    保存的结果,重放时原样返回
error_content TEXT                  失败终态的错误内容
attempt_count INTEGER               执行尝试次数
created_at / updated_at REAL
```

索引:`(user_id, created_at DESC)`、`(turn_id, call_id)`。
设计细节见[工具执行教程](../tutorials/19-工具执行政策与重试.md)。
