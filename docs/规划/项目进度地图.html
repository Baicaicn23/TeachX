什么时候可以上线?

取决于"上线"指什么——分三档,每档差的东西不一样:

🟢 第一档:给人演示 / 录视频

现在就可以,零阻塞
  • 本地一键启动 ./scripts/dev.sh
  • 演示账号、知识库、练习数据已就绪
  • DeepSeek 真实聊天和工具调用已验证
  • 认证、用户隔离、费用护栏全部在工作
  • 不需要公网,不需要 Docker

🟡 第二档:公网演示站(作品集 Demo)

约 3~5 次开发迭代后
  • E6 的基础 trace(可只做最小版)
  • Docker 实机跑通(配置已有,需验证)
  • 服务器/域名 + HTTPS + 密钥轮换
  • 数据库定时备份 + 日志监控(最简)
  • 演示数据一键重置脚本
  • E7~E10 可全部跳过,不影响演示

🔴 第三档:生产级多用户服务

较远,需 E6~E10 全部完成

  • 真实 Embedding 检索质量(E8)
  • 长期记忆与上下文治理(E7)

  • 安全测试(注入/越权)+ 压测
