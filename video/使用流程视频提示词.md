# "TeachX 使用流程"视频生成提示词

> 用法:把下面"提示词正文"整段发给编程 Agent(新对话也行)。
> 它会基于仓库里现成的 `video/` Remotion 项目,生成一个面向用户的
> "TeachX 怎么用"演示视频。

---

## 提示词正文(复制下面整段)

```text

TeachXUsage 的合成(Composition),做一支面向普通用户的"TeachX 使用流程"
演示视频,展示一个学生从注册到形成学习闭环的完整旅程。

硬性要求:

   深色主题(沿用 TeachXDemo.tsx 里的 C 色板)、只用 useCurrentFrame +
   interpolate + spring、不引外部字体图片、离线可渲染。

   Composition(id="TeachXUsage"),不要动已有的 TeachXDemo。
3. 画面形式:用"风格化的浏览器窗口 mockup"模拟界面——一个带红黄绿
   圆点的窗口框,里面是简化的页面(侧栏 + 输入框 + 消息气泡),

4. 用打字机效果模拟流式回答;所有文字用简体中文;视频总时长 55~65 秒,
   1920×1080,30fps。
5. 渲染命令沿用 --browser-executable 指向本机 Chrome,输出
   out/teachx-usage.mp4。

按下面的分镜脚本做(每个镜头一行:时长 | 画面 | 屏幕字幕):

镜头 1(5s)| 深色背景 + 标题卡:"你的 AI 学习助手" · 副标题"从提问到掌握,一个闭环" | 无

镜头 8(7s)| 闭环动画:提问 → 理解 → 反馈 → 练习 → 掌握 五个节点连成一圈,中心显示 TeachX | "学习形成闭环,而不是一次性的问答"
```

## 可选:AI 视频工具的提示词(只适合做氛围片头)

Sora / 可灵 / 即梦 这类工具**不能**用来演示 TeachX 的真实功能(界面会乱画),
但可以生成一个 5 秒的氛围开场(比如"深夜书桌前的学生合上笔记本,屏幕亮起
紫色光芒")。需要的话用这段:

```text
电影感镜头,深夜安静的书房,一名大学生的书桌,笔记本电脑屏幕发出柔和的
紫色光晕照亮桌面,屏幕上是抽象的对话气泡与进度条光影(不出现任何可读文字),
镜头缓缓推近屏幕,氛围安静专注,深色调,4K,5 秒
```

## 更真实的替代:真人录屏镜头清单

动画版胜在可控,录屏版胜在真实。如果想录真的,按这个清单操作
(全程用 Mock 模型启动以免消耗额度,录完剪掉等待):

1. 注册 + 首次引导全流程(挑快节奏剪)
2. 聊天:"什么是特征值?" → 展示流式回答和来源引用
3. "帮我算 19 * 23" → 展示工具调用卡片
4. 回答下点"不清楚" → 写误区 → 学习记录页看错题
5. 练习页:生成题 → 作答 → Good → 掌握度变化
6. 结尾停在聊天页的目标进度条
